# Restaurant Booking

Тестовое задание: форма бронирования столика в ресторане.

## Демо

[Ссылка на приложение](https://restaurant-booking-blond.vercel.app/)

[Репозиторий GitHub](https://github.com/Dendru/restaurant-booking)

## Функциональность

- Создание бронирования.
- Валидация полей формы.
- Валидация при потере фокуса (`onBlur`).
- Отображение сообщений об ошибках.
- Имитация отправки данных с отображением загрузки.
- Экран подтверждения после успешного бронирования.
- Возможность создать новое бронирование.
- Адаптация интерфейса для мобильных и десктопных устройств.
- Базовая CSS-анимация

## Стек технологий

- React 19
- Next.js (Pages Router)
- TypeScript
- CSS Modules

## Запуск проекта

Установка зависимостей:

```bash
npm install
```

Запуск приложения:

```bash
npm run dev
```

Сборка проекта:

```bash
npm run build
```

## Принятые решения

- Для управления состоянием использован `useState`.
- Типы данных вынесены в отдельный каталог `types`.
- Компоненты разделены на форму бронирования и экран подтверждения.
- Для стилизации использованы CSS Modules.
